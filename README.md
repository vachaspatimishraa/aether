## 🔬 8 Specialized Computational Engines

### 1. Precision Scientific Calculator Engine
- **Trigonometric Suite:** Full angle handling in Degrees (DEG) and Radians (RAD) for $\sin, \cos, \tan, \cot, \sec, \csc$.
- **Inverse & Hyperbolic:** $\arcsin, \arccos, \arctan, \sinh, \cosh, \tanh, \text{asinh}, \text{acosh}, \text{atanh}$.
- **Logarithmic Hierarchy:** Arbitrary base $\log_b(x)$, natural logarithm $\ln(x)$, common logarithm $\log_{10}(x)$, and binary $\log_2(x)$.
- **Exponential & Powers:** $x^2, x^3, x^y, \sqrt{x}, \sqrt[3]{x}, \sqrt[y]{x}, 10^x, e^x$.
- **Combinatorics:** Permutations ($nPr$), Combinations ($nCr$), and large-integer Factorials ($n!$).
- **Memory Register:** 5-key persistent memory suite (`MC`, `MR`, `M+`, `M-`, `MS`).
- **Constants Sheet:** Quick-insertion sheet for fundamental physical constants ($\pi, e, \phi, c, h, \hbar, G, N_A, k_B, R, \sigma$).

### 2. Interactive 2D Cartesian Function Grapher
- **Hardware-Accelerated Canvas:** Custom Cartesian coordinate plotting with sub-pixel anti-aliasing.
- **Dynamic Gestures:** Fluid panning and multi-touch pinch-to-zoom across variable coordinate intervals.
- **Inspector Crosshair:** Tap or drag across any curve to inspect exact $(x, y)$ coordinate pairs, local extrema, and axis intercepts.
- **Quick-Range Presets:** Instant window framing for Trigonometric, Polynomial, Rational, and Standard Cartesian intervals.

### 3. 32-Bit Synchronized Programmer & Bitwise Logic Engine
- **Synchronized Radix Conversion:** Simultaneous real-time display across **HEX** (Hexadecimal), **DEC** (Decimal), **OCT** (Octal), and **BIN** (Binary).
- **Interactive 32-Bit Visual Flipper Grid:** Click any individual bit (0–31) to toggle its state live with synchronized updates.
- **Bitwise Logic Operators:** `AND`, `OR`, `XOR`, `NOT`, `NAND`, `NOR`, `XNOR`.
- **Bit Shifting & Rotation:** Logical/Arithmetic Left Shift (`<<`), Right Shift (`>>`), Rotate Left (`ROL`), Rotate Right (`ROR`).

### 4. Advanced Matrix & 3D Vector Linear Algebra Suite
- **Matrix Operations (2×2 and 3×3):**
  - Matrix Determinant ($\det(A)$)
  - Matrix Inversion ($A^{-1}$) via adjugate cofactor expansion
  - Matrix Transpose ($A^T$)
  - Matrix Trace ($\text{tr}(A)$)
  - Characteristic Polynomial coefficients
- **3D Vector Algebra:**
  - Dot Product ($\vec{u} \cdot \vec{v}$)
  - Cross Product ($\vec{u} \times \vec{v}$)
  - Euclidean Norm ($||\vec{u}||$)
  - Spatial Angle ($\theta$) between vectors in degrees and radians

### 5. Polynomial & Simultaneous Linear Equation Solver
- **Quadratic Solver:** $ax^2 + bx + c = 0$ with discriminant analysis and complex conjugate root handling.
- **Cubic Solver:** $ax^3 + bx^2 + cx + d = 0$ using Cardano's analytical trigonometric reduction.
- **2×2 Simultaneous Linear System:** $a_1 x + b_1 y = c_1$, solved via Cramer's Rule with singular matrix detection.
- **3×3 Simultaneous Linear System:** Complete $3\times3$ system solution with determinant verification.

### 6. Multi-Category Unit Conversion Matrix
- **8 Comprehensive Physical Domains:** Length, Mass, Temperature, Speed, Data Storage, Pressure, Energy, and Time.
- **Live Bidirectional Matrix:** Enter a value in any unit to see an instant, sorted comparison table across all category equivalents.

### 7. Financial TVM & Wealth Projection Engine
- **Compound Interest Projector:** Calculates Future Value ($FV$), total contributions, interest yield, and compound frequency compounding.
- **Loan & Mortgage EMI Calculator:** Monthly payment evaluation with total interest paid and principal breakdown.

### 8. Statistical & Probability Suite
- **Descriptive Dataset Metrics:** Mean ($\mu$), Median, Mode, Standard Deviation ($\sigma, s$), Variance ($s^2$), Range, and Interquartile Range ($IQR$).
- **Sample Space Combinatorics:** Exact calculation of binomial coefficients and permutations for large sets.

## 🛠️ Build & Installation Guide

### Prerequisites
- [Flutter SDK](https://flutter.dev) (v3.13.7 or higher, tested on 3.47+)
- Android SDK Platform 35 & Command-Line Tools
- Java Development Kit (JDK 17)

### 1. Android Builds
```bash
# Compile signed Google Play Android App Bundle (.aab)
flutter build appbundle --release

# Output:
# build/app/outputs/bundle/release/app-release.aab

# Compile signed standalone Release APK
flutter build apk --release

# Output:
# build/app/outputs/flutter-apk/app-release.apk

# Install directly to connected Android phone
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

### 2. Web Build & Standalone PWA
```bash
# Compile production Flutter Web build
flutter build web --release

# Standalone single-file zero-dependency PWA (runs in any browser without build tools)
open web_standalone/index.html
```

### 3. Linux Desktop Native
```bash
# Compile native 64-bit Linux binary
flutter build linux --release

# Run native binary
./build/linux/x64/release/bundle/test
```

### 4. Automated Testing
```bash
# Run comprehensive unit & widget test suite
flutter test
```
